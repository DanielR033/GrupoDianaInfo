5. Adelanto Fase 3 – Tesorería / Siembra

Cómo empatar la iniciativa al Gobierno (prioridad, control y trazabilidad)

1
Alta
Formalizar el dato en el Catálogo
  • Definiciones, reglas de negocio, propietarios
  • Calidad esperada, frecuencias, excepciones
  • Responsable : Metadata & Catalog Lead
2
Alta
Incorporar la iniciativa en el Modelo de Dominios
  • Asociar dominios: Comercial/RTM/Ventas, Financiero, Producción/Logística (si aplica)
  • Asignar Data Owner y Data Steward
  • Responsable : Data Governance Director (DGD)
3
Alta
Aplicar Gobierno Técnico sobre el pipeline
  • Versionamiento, auditoría, trazabilidad de jobs
  • Reglas de calidad (DQ) y lineaje automático
  • Responsable : Data Quality & Trust Lead
4
Alta
Corregir accesos y políticas de seguridad
  • Roles por dominio y clasificación de sensibilidad
  • Minimización en Power BI/Lakehouse; control por workspace
  • Responsable : Data Security & Privacy Officer
5
Media
Integrar a Lakehouse bajo arquitectura estándar
  • Bronze (crudo)
  • Silver (validado)
  • Gold (KPI y métricas)
  • Responsable : Data Architecture & Life Cycle Manager
6
Media
Documentar flujo extremo a extremo
  • Origen → transformación → destino → consumo
  • Soporte a auditoría y riesgos
  • Responsable : DGD
7
Media
Tablero de monitoreo de calidad y operación
  • Freshness
  • Errores de ingesta
  • Reglas fallidas
  • Volumen esperado vs. obtenido
  • Responsable : DGD
8
Baja
Comunicar formalmente al Comité de Gobierno
  • Qué se hizo
  • Riesgos actuales
  • Remediación propuesta
  • Responsable : DGD

Lectura ejecutiva: la iniciativa entra a Fase 3 como un “producto de datos con Gobierno”, no como un desarrollo aislado. Esto acelera auditoría, reduce reprocesos y mejora adopción.

6. Roadmap y cierre

El Gobierno habilita el salto a ejecución (sin perder rigor)

Lo que queda para cerrar Fase 2
  • Formalizar procedimientos (versionado final y socialización)
  • Plan de adopción: calendario de capacitación + taller primer dominio
  • Backlog priorizado para OLA 1 (dominios e iniciativas Siembra)
Señales de continuidad (Alta tracción)
  • Modelo operativo + comités listos para operar
  • Arquitectura To‑Be/Transición cerrada para implementación
  • Dominios priorizados + cruce con Siembra
Mensaje final para el Comité

Estamos en un punto “bisagra”: el Gobierno ya tiene forma (roles, comités, procedimientos) y la arquitectura está lista para ejecución. El éxito de Fase 3 se define por la adopción: acelerar capacitación, poner a operar el modelo y ejecutar el primer dominio como caso ejemplar.
